## 2. 良い点

- 配色が紺 1 色+灰色背景+白カードに絞られていて、Studio と生成アプリで色の使い方がそろっている(主ボタン=紺の塗り、副ボタン=白地に枠線)。
- 生成アプリのヘッダ(アイコン・アプリ名・ピル型のナビ・右端のログイン)は形が整っていて、今いる画面が薄い紺の背景で分かる(`app-list` / `app-mine` / `app-admin`)。
- 一覧は PC では表、スマホでは「ラベル左・値右」のカードに切り替わり、390px でもはみ出していない(`app-list-390`)。数字の列が右寄せになっている。
- 日付が「2026年12月5日(土) 19:00」、金額が「¥1,000」と日本式に整形されている。
- 管理フォームは PC では 3 列、スマホでは 1 列に並び替わる。入力欄は高さ約 48px で押しやすく、「必須」バッジと「例: 3」の入力例が付いている(`app-admin`)。
- Studio の左の一覧は、見出しに「役割(だれが何をできるか)」「集計(決まった名前の表)」のような言い換えが付いていて、専門用語を和らげている(`studio-home-1280`)。
- 上部の「✓ 検査に合格」バッジで、今の状態が一目で分かる。
- 「見た目の確認」で複数の機種を並べて見比べられ、機種名と画面サイズが下に書いてある(`studio-tab-見た目-1280`)。
- axe(アクセシビリティ検査)の違反は全画面で 0 件。

## 4. 「素人っぽさ」を消すために、いちばん効く 3 つの直し

1. **詳細画面に紺の大きな「予約する」ボタンを置き、ピンクのエラー帯をやめる**(`app-detail`)。
   このアプリの目的そのものである操作が見えないうえ、エラー色が 2 本並んでいて、最初の印象で「壊れている」と思われてしまいます。見出しをイベント名にして、ボタンをカードの直下に置けば、それだけで「ちゃんとした予約サイト」に見えます。

2. **機械が書いた言葉と英語式の表示を、人の言葉に置き換える**(`app-mine` / `app-admin` / `app-list` / `app-login`)。
   置き換える例:
   - 「データがありません」→「まだ予約はありません」+「イベントを探す」ボタン
   - 「送信」→「イベントを登録する」
   - 「mm/dd/yyyy」→ 年/月/日の順の表示
   - 「イベントの一覧」の重複見出し → 削除

   ほかに、「定員」「予約数」を「残り 3 席」にする、ログイン画面にもヘッダを付ける、もあります。どれもレイアウトを変えずに済み、効果が大きい直しです。

3. **Studio のスマホ幅を作り直す**(`studio-*-390`)。
   - タブは横スクロールにして 1 行に収める。
   - 「動かす」タブの表は `overflow-x:auto` の入れ物で包み、横のはみ出しをなくす。
   - 「見た目の確認」の端末は 1 台ずつ切り替える方式にし、白いまま写る状態をなくす。

   今は文字が 1 文字ずつ縦に並んで、画面も横にはみ出しているため、作る人がスマホで開いた瞬間に「未完成の道具」に見えます。
