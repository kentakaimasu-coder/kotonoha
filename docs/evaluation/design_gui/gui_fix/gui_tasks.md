# 直してほしいこと(できあがったイベント受付アプリへの、よくある小さな直し)

あなたの作業フォルダの G/ に、もう動く「イベント受付」アプリがあります(だれかが作ったもの)。
使っている人から、次の 12 個の直しを頼まれました。**Studio の画面だけで**、上から順に直してください。
1 つ終わるごとに「✓ 検査に合格」のままか、アプリの画面で直ったかを確かめます。できなければ諦めて次へ進んで構いません(正直に記録)。

1. アプリの色を緑にしたい
2. 画面のいちばん上に出るアプリの名前を「市民講座の申込」にしたい
3. 詳細の画面のボタン「1名で予約」の文字を「申し込む」にしたい
4. 予約が満席のときに出る「満席」の言葉を「定員に達しました」にしたい
5. イベント一覧を、開始日時の早い順に並べたい
6. イベント一覧には、まだ始まっていない(開始日時が今日以降の)イベントだけを出したい
7. イベントに「持ち物」の項目を足したい(空でもよい)。詳細の画面にも出したい
8. 詳細の画面から「2名で予約」のボタンを消したい
9. 画面「自分の予約」の名前を「マイ予約」にしたい
10. イベントの「参加費」を空でもよい(無料のときは書かない)ようにしたい
11. 「管理」の画面は主催者だけのメニューにしたい
12. アプリを開いたときに最初に出る画面を「自分の予約」(9 で名前を変えたなら「マイ予約」)にしたい
