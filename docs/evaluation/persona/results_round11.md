このテストで、足す欄の不具合がさらに 2 つ見つかり、直した: 足した行が編集の欄に出ない(書きかけの欄があると描き直さなかった)、読めなかったときの理由が出ない

## 4. 300% 基準に対する判定
- **本人の見積もり: 平均 3.22 倍・中央 3 倍で、4 回続けて平均 3 倍を超えた。** ただし 3 倍以上は 20 人(第 10 回 27 人)に減った。
  下がった人の多くは C で「ほかのデータの数を変える処理」をソースで書いた人で、SUS が上がったのとは逆の動きになった
- **SUS: 未達(2.50 倍)。** 68.1 点は第 4 回以来の最高だが、3 倍(81.6 点)には遠い
- **行動の指標**: コマンド 0 回。A でソースを書いた人 0 人(第 7 回 30 人)
- 判定(利用者と合わせた方法): **本人の見積もり(平均)と行動の指標では 3 倍を満たした。主観の SUS は満たしていない。**
  評価中に入れた修正が別の不具合を生んだので、第 12 回からは修正を入れるたびに、ペルソナが通る操作(足す欄・上の欄の両方)を自動の確かめに足す
