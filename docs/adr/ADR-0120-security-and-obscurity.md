# ADR-0120 セキュリティ強化と「知られていないこと」の扱い
状態: 提案(実装) / 日付: 2026-11-07 / 関連: NR-02, NR-03, SEC-01〜10

## 背景
依頼者の必須要件に「ほかのオープンソースと違ってまだ知られていないからセキュリティが高いこと」がある。

## 決定(案)
1. 「未知であること」はセキュリティの根拠にしない(security through obscurity は、公開・流出・解析で消える)。KOTONOHA の安全性は、仕様と実装がすべて公開されても成り立つことを前提に設計・試験する。
2. 依頼者の意図は、次の測定可能な性質として実装する: 攻撃面の最小化、定番フレームワークのサーバー実装に依存しない生成コード、痕跡(製品名・バージョン)を出さない応答、負例テストで裏付けた認証・認可。
3. 痕跡の除去は**多層防御の補助**であり、主たる防御ではない。
4. リポジトリの公開範囲は依頼者が決める(現在 public)。

## 実装
NR-02 の項目(docs/requirements/03_requirements_addendum.md)。ヘッダ・Cookie 名・ヘルスチェックの変更は既存クライアントに影響しない(Web は同梱、モバイルは API のみ使用)。
