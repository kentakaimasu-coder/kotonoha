# ADR-0101 字句規則
状態: 提案 / 日付: 2026-11-02 / 関連: C-01, U-10, FR-001
## 決定(案)
1. 語 = `_`・Unicode の英字・数字の**最長一致**。助詞は自動分割しない。予約語は語全体が一致したときだけ。
2. 予約語 `を返す` `を確認` は前を空白で区切る(`注文ID を返す`)。`注文IDを返す` は SYN001 + 修正ヒント。
3. 非 NFC のソースは正規化せず SYN002 で拒否(位置情報の一貫性。`koto fmt` が正規化)。
4. コメントは `#`。全角 ASCII・全角空白・タブは SYN001(自動同一視しない: 技術仕様 §3.2)。
5. 記号に `!`(否定)と `@`(注釈)を追加。
## 代替案
- 助詞(を/で/に/の/と)で語を分割: `商品をIDで取得` のような識別子が書けなくなり、識別子にどの助詞が含まれるかで意味が変わる。却下。
- NFC に自動正規化: 列番号がソースとずれる。却下。
## 影響
仕様書 §2 のサンプルは 1 箇所(`注文IDを返す`)修正が必要。
