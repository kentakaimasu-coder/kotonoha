# ADR-0118 Capability の粒度(問題提起)
状態: 未決定 / 日付: 2026-11-03 / 関連: 技術仕様 §9、SEC-01、ADR-0105
## 問題
仕様 §9 は「呼出グラフ上の必要権限を集約」し、実行時に主体が全 Capability を持つことを要求する(実装済み)。この方式では、購入者が `注文する` を使うには `商品.update`(在庫を減らすため)が必要になり、**同じ主体が `商品.update` を必要とする他の動作(例: 価格変更)も呼べてしまう**。
## 選択肢
1. 動作単位の許可(`動作.注文する` の実行権)を主体に与え、資源 Capability は静的検査だけに使う
2. Capability に対象行の条件を付ける(本人の注文のみ等: 行レベル認可)
3. 現状のまま(資源単位)。管理系の動作を別 Capability(例: `商品.管理`)に分ける運用で回避
## 推奨
1 + 2。決定までは現状(仕様どおり)で実装し、変更しない。
