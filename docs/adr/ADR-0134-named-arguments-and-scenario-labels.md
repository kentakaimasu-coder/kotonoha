# ADR-0134 名前付き引数と、「確かめる」で作った物に名前を付ける
状態: 提案(実装) / 日付: 2026-11-09 / 関連: 第 4 回ペルソナ評価(results_round4.md §1・§4)、ADR-0130

## 背景
- ADR-0130 で `予約を登録(枠ID, 本人, 人数, 現在日時())` と**位置で渡す**登録になり、項目名がデータの宣言にしか出なくなった。
  第 4 回では 29 人が、課題の項目名(参加者)と違うひな形の項目名(予約者)のまま気づかなかった
- 「確かめる」では ID が自動で決まる物(作った予約・申請)を後の行で使えず、取消・承認の流れを書けなかった(E23・E26・E29)

## 決定(提案)
1. **名前付き引数**: 呼び出しの引数を `項目名: 値` で書ける(動作・データの操作・関数・外部関数)。
   `予約を登録(枠ID: 枠ID, 予約者: 本人, 人数: 人数, 予約日時: 現在日時())`
   - 型検査の前に宣言の順に並べ替える(書く順は自由)。以降は位置で渡した呼び出しと同じ(生成物は変わらない)
   - `選択<…>` の引数は省ける(なし)。無い名前・2 回・省けない引数の不足・名前付きと位置の混在はエラー(使える引数を示す)
   - ひな形 4 つと `koto patterns`・チュートリアルを名前付きの書き方にした(項目名が登録の行に見える)
2. **「確かめる」の結果に名前**: `→ 成功(問1)` で動作が返した ID に名前を付け、後の行の引数や `問い合わせ(問1)の状況は 完了` で使える。
   名前は「確かめる」ごと(別の「確かめる」からは見えない)
