# ADR-0141 「…はログインした人だけ閲覧可」と役割の無い人
状態: 提案 / 日付: 2026-11-17 / 関連: ADR-0140(役割を書かない人の権限)、[第 14 回評価](../evaluation/persona/)

## 背景
第 14 回の評価で、役割(会計係・メンバー)のあるアプリに「収支はログインした人だけ閲覧可」と書いたのに、
役割の無い人でログインすると一覧が 403 になった(N11)。作り手は「ログインした人なら誰でも見られる」と読んでいた。

いまの意味は「未認証なら不可」で、読むにはさらに `収支.読取` の権限が要る。役割のあるアプリでは、
役割の無い人は役割に関わらない権限だけを持つ(ADR-0140)ので、役割に `収支.読取` が付いていると読めない。
Studio はこの約束を書いたとき役割に読取を足している(第 13 回)ので、かえって役割の無い人が読めなくなる。

## 選択肢
1. いまのまま(ログインした人だけ = 未認証なら不可。読むには読取の権限も要る)。Studio で書いたときに
   「見られるのは役割の付いた人です」と知らせる(第 14 回の途中で入れた)
2. 「ログインした人だけ閲覧可」のデータの読み取り(一覧・詳細・集計)は、読取の権限を求めず、ログインしていれば読める
   (公開の点検の「だれが何を見られるか」も「ログインした人みんな」と出す)。本番で役割の無い人も読める
3. 新しい文型「…は役割のある人だけ閲覧可」を足し、「ログインした人だけ閲覧可」は 2 の意味にする

## 推奨案(提案)
2 を推奨する。文の読み方と動きが合い、役割の無い人を作り手が意識しなくてよい。
ただし認可の意味が変わる(本番で読める人が増える)ので、既存のアプリへの影響(公開の点検での差分表示)を含めて
利用者(作り手)の承認が要る。決まるまでは 1 のまま
