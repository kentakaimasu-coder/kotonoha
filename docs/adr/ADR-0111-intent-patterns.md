# ADR-0111 意図文型・画面の入力・約束文型
状態: 提案 / 日付: 2026-11-02 / 関連: U-15, U-16, I-01
1. 画面の文型は P-LIST / P-FIELDS / P-KNOWLEDGE(-N) / P-NAV / P-BUTTON の 5 つ(docs/spec/intent_patterns.md)。字面の接頭辞・接尾辞 + 宣言名の完全一致で照合し、形態素解析は使わない。
2. 画面の入力は、その画面への P-NAV 遷移が渡すデータで決める。
3. 約束の文型は C-PUBLIC(`{D}は誰でも閲覧可`)と C-AUTH(`未認証なら{D}不可`)のみ。行レベル認可(「本人だけ閲覧」)は主体と所有者の対応付けの設計(ADR-002 と連動)が必要なため文型を定義せず AMB001。
4. 文型の追加は、この ADR とテストの更新を伴う変更としてのみ行う。
