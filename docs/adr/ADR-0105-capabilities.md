# ADR-0105 Capability と効果の宣言
状態: 提案 / 日付: 2026-11-02 / 関連: C-03, TC-006, SEC-01
## 決定(案)
1. ソースの動詞は 読取/作成/更新/削除、VAG では read/create/update/delete。
2. `必要 = [...]` が無い動作が資源に触れたら SEC002(デフォルト拒否)。
3. **更新は読取を含まない**。`商品をIDで取得` を呼ぶ動作は `商品.読取` が必要。
4. 任意の `効果 = [...]`(`pure` 可)を宣言すると、宣言外の効果は SEC001。
5. 呼び出した動作の Capability は呼出元にも必要(推移閉包)。
## 代替案(3)
「更新 ⊇ 読取」にすれば仕様書 §2 のサンプルがそのまま通る。最小権限の観点で不採用を推奨するが、承認者の判断事項。
