# ADR-0124 関数・組込み関数・外部関数(TypeScript / Python)
状態: 提案(実装) / 日付: 2026-11-07 / 関連: NR-05, NR-06

## 背景
依頼者の要件「今までの既存言語をある程度カバーし、今までにない拡張性を持ち、使いやすい」「機械学習など(Python)の機能を兼ねる」。
業務ロジックは厳密層で検証可能に保ちつつ、既存の資産(npm・Python の数値計算/機械学習)を**型付きの境界**越しに使えるようにする。

## 関数(副作用なし)
```kotonoha
関数 値引き後(価格: 金額<JPY>, 値引き: 金額<JPY>) -> 金額<JPY>:
    もし 値引き > 価格:
        価格 - 価格 を返す
    価格 - 値引き を返す
```
- 本体は厳密層。アダプタ・動作・外部関数の呼出、`本人`、`現在日時()`、`取引:` は使えない(SEC001)。全ての経路で値を返す(TYP003)
- 動作・他の関数から呼べる。backend では同期関数として生成する

## 組込み関数
`長さ(文字列)`(Unicode スカラー値の数)・`件数(一覧)`・`絶対値`・`最大`・`最小`・`文字列化(整数|金額)`・`含む(文字列, 文字列)`・`現在日時()`(動作の中だけ)。
同名の関数・外部関数を宣言したら利用者の宣言が優先する。

## 外部関数
```kotonoha
外部関数 割引額(価格: 金額<JPY>) -> 金額<JPY>:
    実装 = "ext/pricing.ts"

外部関数 需要予測(商品ID: 識別子, 価格: 金額<JPY>) -> 整数:
    実装 = "ml/forecast.py"
    効果 = [pure]            # 既定。ネットワーク等を使うなら宣言する(呼ぶ動作の効果に伝わる)
```
- 実装ファイルはプロジェクト内の相対パス(`..`・絶対パス・ドライブ指定・プロジェクト外へのシンボリックリンク不可。1 MiB 以下の UTF-8)。拡張子 `.ts` / `.py`
- 引数・戻り値はワイヤ形式(API と同じ JSON)で受け渡しできる型だけ(TGT001)
- **戻り値は実行時に宣言型で検証する**(信頼しない)。型違いは 422 `external_type`、例外は 422 `external_failed`。応答に内部の詳細を出さない
- TypeScript: 部品名と同名の名前付きエクスポート。backend の同じプロセスで実行
- Python: 1 ファイル 1 つの常駐ワーカー(`python3 -I`、環境変数を引き継がない、JSON 行プロトコル、`KOTONOHA_EXT_TIMEOUT_MS`(既定 10 秒)で打ち切り・再起動)。`KOTONOHA_PYTHON` で実行ファイルを指定
- 宣言した効果は、呼んだ動作(推移的に)の効果に加わり、効果宣言との不一致は SEC001
- 実装ファイルの SHA-256 は VAG(`extensions.functions`)に入り、ロックで固定される

## 未決定・制約
- 外部関数のコードはサンドボックス化しない(信頼できるコードとしてレビュー・ロックする前提)。OS レベルの隔離(コンテナ・seccomp)は運用で行う
- Python の依存パッケージ(scikit-learn 等)の導入・固定は利用者の環境に任せる(SBOM には含まれない)
- iOS / Android / Web からは外部関数を直接呼ばない(backend の動作経由のみ)
