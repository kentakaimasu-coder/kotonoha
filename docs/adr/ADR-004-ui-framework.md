# ADR-004 UI 生成フレームワーク
状態: 未決定(暫定実装あり) / 日付: 2026-11-02 / 更新: 2026-11-03
## 背景
要件 §7「TypeScript/React ベース(SSR 対応)」。具体的な SSR 基盤・ルーティング・状態管理が未定。
## 選択肢
1. React + Vite SSR(最小依存、生成コードが読みやすい)
2. Next.js(App Router)(SSR/ルーティングが標準、フレームワーク更新の追従コスト)
3. React Router v7(framework mode)
## 推奨
1 または 3。生成物の再現性(FR-020)と依存固定(SEC-07)を優先し、フレームワークの規約に依存する部分が少ない方を選ぶ。決定前に「商品一覧+詳細+購入ボタン」の生成テンプレートを 2 案で試作し比較する。
## 暫定実装(2026-11-03)
推奨案 1 を簡素化し、**React 19 の SSR + esbuild(クライアントバンドル)**、サーバーは Node 標準の http で実装した。Vite を使わないのは依存を減らすため(SEC-07)。フレームワーク固有の規約に依存しないので、Next.js 等への切り替えは生成器の差し替えで済む。
