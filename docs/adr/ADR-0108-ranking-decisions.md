# ADR-0108 売れ筋の業務決定と時刻境界
状態: 提案(業務値は未承認) / 日付: 2026-11-02 / 関連: U-12, U-13, U-17, AT-07
## 決定(案)
1. 知識宣言に `日時列` `時刻帯` `税区分` `条件` を必須キーとして追加。欠けたら AMB001(質問)。
2. 区間は `[基準日時 - N 日, 基準日時)`。基準日時は実行時入力。
3. 時刻帯は固定オフセット(Asia/Tokyo, UTC)のみ対応。他は TGT001(tz データベース導入は将来)。
4. 並びは単位列を含むことを要求(同順位の決定性)。
## 承認待ちの業務値(examples のフィクスチャ)
状態=確定(取消除外)/ 税込 JPY / Asia/Tokyo / 30 日 / 売上金額の合計 / 20 件 / 売上金額の降順・商品IDの昇順。返品の別テーブル調整は対象外。
