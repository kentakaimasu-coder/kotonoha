# ADR-0110 物理マッピングと SQLite 格納形式
状態: 提案 / 日付: 2026-11-02 / 関連: U-18, ADR-003
- 表名・列名は宣言名をそのまま二重引用符付き識別子として使う(恒等写像)。`"` や制御文字を含む名前は GEN001(字句規則上は発生しない)。
- SQLite: 整数/真偽/日時(UTC エポックミリ秒)/金額<JPY>(円)= INTEGER、文字列/識別子/URL/メール/列挙 = TEXT(列挙は CHECK 制約)、非選択型は NOT NULL、`ID` は PRIMARY KEY。
- PostgreSQL の DDL は未実装。
- 代替案: `@表("order_items")` 等の注釈で物理名を指定。既存 DB 接続(要件 R6)で必要になるため M2 で追加検討。
