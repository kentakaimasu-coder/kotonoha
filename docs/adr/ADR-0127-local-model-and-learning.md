# ADR-0127 手元のオープンモデルと、承認から育つ解釈(学習記録)
状態: 提案(実装) / 日付: 2026-11-08 / 関連: ADR-006(外部 AI と送信方針: 未決定のまま)、FR-006、NFR-010、SEC-08、不変ルール 2

## 背景
「オープン型の AI モデルで自己成長できるようにしたい」という要望。外部の AI へソースを送る方針(ADR-006)は
未決定のため、外部送信をしない形で、AI による候補作成と「使うほど当たるようになる」仕組みを入れる。

## 決定(提案)
1. **`local` アダプタ**: OpenAI 互換の `/chat/completions` を持つ手元のサーバー(Ollama・llama.cpp server・vLLM など)
   に候補を出させる。`koto resolve --adapter local --model <名前> [--endpoint URL]`(既定 `http://127.0.0.1:11434/v1`)
   - 接続先は**ループバック(127.0.0.0/8・::1・localhost)の http だけ**。それ以外は拒否する(ADR-006 が決まるまで外部送信はしない)。
     名前解決の結果もループバックであることを確かめる
   - 送る内容は「解釈する文・確認事項・使える正規文の例(最大 30 件、宣言名を含む)・似た文の過去の承認(最大 5 件)」だけ。
     ソース本文・知識の値・データの中身は送らない
   - 温度 0・seed 0 で問い合わせる(ただし出力の決定性はモデル・サーバー次第。パイプラインは候補ファイルを読むだけなので、
     ビルドの決定性(不変ルール 6)には影響しない)
   - 出力は未信頼データ。文章から JSON オブジェクトを 1 つ取り出し、`intent_id`・`sentence_hash`・根拠はこちらで上書きして、
     既存の厳格なスキーマ検査(余分なキー・未知の効果・改行入りの正規文を拒否)→ 既知の文型での再照合(成立しない解釈は除外)
     → 人の承認、の順を通す。モデルの出力を実行・評価することはない(不変ルール 2)
2. **`memory` アダプタ**: モデルを使わず、同じ文が過去に承認された解釈を候補に出す(AI なし・決定的)
3. **学習記録**(`koto learn`): 置き場所は `KOTONOHA_LEARN_DIR`、無ければ `~/.kotonoha/learn`(プロジェクトをまたいで育つ)
   - `koto learn init` で有効にした人だけ、`koto approve` のたびに「文 → 承認した正規文」「選ばなかった候補」「見せた正規文の例」を記録する
   - `koto learn collect`: 今のプロジェクトの承認記録を取り込む
   - 候補作成時に似た文の承認例を見せる(追加学習なしで当たりやすくなる)。同じ文の承認済み解釈は候補の先頭に置く
   - `koto learn export --out dir`: 追加学習用の `sft.jsonl`(chat 形式)と `dpo.jsonl`(選ばれた/選ばれなかった)。
     書き出す問いには、その文自身の答えを含めない
   - `koto learn eval --model <名前> [--min 0.8]`: 記録の各文を、その文を除いた記録だけを例にしてモデルに解かせ、
     1 番目の候補が承認と一致した割合を測る。結果は `evals.jsonl` に残し、`koto learn status` で推移を見られる。
     `--min` を下回れば失敗で終わる(劣化したモデルを入れないための関門)
4. 記録から**自動で承認することはない**。育つのは「候補の質」だけで、採否は常に人が決める

## 採らなかった案
- 外部の AI サービスへの送信: ADR-006 の決定待ち
- KOTONOHA の中での追加学習: 学習の道具(TRL・Unsloth など)と GPU 環境は利用者ごとに違うため、データの書き出しと評価だけを持つ
- 承認が N 回そろった言い換えを自動で文型に昇格: 承認の範囲(ADR-0112)を越えるため見送り。将来、提案の一覧として出す余地はある

## 検証の範囲
- 模擬の OpenAI 互換サーバーで、接続先の制限・JSON の取り出し・chunked 応答・注入された出力の拒否・承認から学んで当たりやすくなる流れ・
  書き出し・評価の関門を自動テストしている(crates/resolver/src/local_tests.rs、crates/cli/tests/cli.rs)
- **実際のオープンモデル(Ollama 等)での動作と、追加学習したモデルの効果は、この開発環境からモデルを取得できないため未検証**
