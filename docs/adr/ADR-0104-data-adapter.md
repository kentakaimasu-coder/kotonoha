# ADR-0104 データアダプタ宣言
状態: 提案 / 日付: 2026-11-02 / 関連: C-02, U-14
## 決定(案)
```kotonoha
アダプタ 商品をIDで取得(ID: 識別子) -> 商品:
    操作 = 取得(商品)
```
- 操作種別は 取得/一覧/登録/更新/削除 の 5 つ。種別から効果と Capability を**機械的に導出**する(宣言者が偽れない)。
- 型規則は docs/spec/type_system.md §4。`登録` では ID を引数にできない(生成される)。`一覧` の絞り込みは未対応。
- `取得` の戻り型は `D` か `選択<D>`。`D` の場合「見つからなければ実行時エラー(HTTP 404 相当)」とする案だが、実行時意味論は Backend 生成(M2)で確定する。
## 代替案
- データ宣言から CRUD を自動提供: 仕様書 §2 注「標準提供ではない」に反する。不採用。
