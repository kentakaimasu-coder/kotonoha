# 知識定義の値の文法

状態: 提案(ADR-0108) / 最終更新: 2026-11-02 / 上位文書: 技術仕様書 §8, FR-005 / 実装: `crates/knowledge`

MVP で扱える知識の形状は **集計ランキング** だけ(`指標` を持つ)。それ以外の形状は AMB001。

| キー | 必須 | 値の書式 | 検査 | 不正時 |
|---|---|---|---|---|
| 別名 | 任意 | `[語, 語]` | 知識名・別名はプロジェクト内で一意、型名と衝突しない | AMB002 |
| 対象 | ✔ | データ名 | 存在 | REF001 |
| 期間 | ✔ | `直近N日`(N=1〜3650、先頭 0 不可) | | AMB001(質問) |
| 指標 | ✔ | `{フィールド}の合計` / `件数` | 合計は 整数 か 金額。選択型は NULL 扱い未確定、小数は精度未決定 | AMB001 / TYP001 |
| 単位 | ✔ | フィールド名 | 存在。選択型は AMB001 | REF001 |
| 並び | ✔ | `{列}の降順` / `{列}の昇順` を `,` 区切り | 列は 単位 か 指標の結果列。**単位を含む**こと(同順位の決定性) | REF001 / AMB001 |
| 件数 | ✔ | 整数 1〜10000 | | AMB001 |
| 日時列 | ✔ | フィールド名 | 型が 日時 | REF001 / TYP001 |
| 時刻帯 | ✔ | `Asia/Tokyo` / `UTC` | 対応表に存在 | TGT001 |
| 税区分 | ✔ | `税込` / `税抜` | | AMB001 |
| 条件 | ✔ | `なし` または厳密層の式(対象のフィールドを変数として参照) | 真偽型、呼出不可 | TYP001 |

技術仕様書 §8 の 6 キーに **日時列・時刻帯・税区分・条件** を必須として追加した(§8「追加で必須の業務決定」を、欠けたら質問になる形で強制するため)。

## 意味
- 区間は `[基準日時 - N 日, 基準日時)`。基準日時は実行時の入力(既定は現在時刻)。固定オフセットの時刻帯では「N 暦日前の同時刻」と「N×24 時間前」は一致する。夏時間のある時刻帯は未対応。
- 結果の型は `一覧<記録{単位: T, 指標列: U}>`。指標列名は合計ならフィールド名、件数なら「件数」。
- 画面の `{知識}を{N}件表示` は件数だけを上書きする。

## 正式採用前に承認が必要な仮定(examples のフィクスチャ)
状態=確定(取消を除外)、税込 JPY、Asia/Tokyo、区間 `[基準日時-30日, 基準日時)`、NULL 金額は型で禁止(非選択型)。返品の別テーブル調整は未対応。
