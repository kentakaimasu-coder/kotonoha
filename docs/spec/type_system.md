# 型システム仕様

状態: 提案(ADR-0102/0105/0106) / 最終更新: 2026-11-02 / 上位文書: 技術仕様書 §4 / 実装: `crates/types`

## 1. 型
| 分類 | 型 | 備考 |
|---|---|---|
| プリミティブ | 真偽, 整数(i64), 小数, 文字列, 日時, 日付, 識別子, バイト列 | 小数の精度は ADR-0106 未決定 |
| ドメイン | 金額<通貨>, 期間, URL, メールアドレス | 通貨は英大文字 3 文字 |
| 合成 | 配列<T>, 一覧<T>, 選択<T>, 結果<T,E>, 記録{名前: T, …} | `選択<選択<T>>` は TYP001 |
| ユーザー定義 | データ(名目型), 列挙(名目型), 型の別名(**透過的**) | |
| 内部 | なし(Unit: 戻り値なし), エラー(回復用) | |

組込み型名と同名の宣言は REF002。型名・呼出名(アダプタ/動作)・知識名・画面名は別の名前空間。変数は値の名前空間(型名と同じ名前の変数は可。アダプタ/動作と同名の変数は REF002)。

## 2. 型付け規則(主要部)
- **暗黙変換なし**: 数値↔文字列、整数↔小数。
- `T` は `選択<T>` が期待される位置で受け入れる。`なし` は `選択<T>` が期待される位置でのみ。
- 文字列リテラルは、列挙型 E が期待される位置で E の値名に一致すれば E 型。一致しなければ TYP001(候補をヒント表示)。
- `結果<T,E>` を返す動作で `x を返す` の x は T でもよい(`成功(x)` に自動で包む)。
- `C を確認 または 失敗(e)`: C は真偽、e は動作の戻り型 `結果<T,E>` の E。戻り型が結果でなければ TYP001。

### 演算
| 演算 | 規則 |
|---|---|
| `+ - * /` | 整数⊕整数→整数(`/` は 0 方向切り捨て。オーバーフロー・0 除算は実行時に検査し失敗にする: 実行時は未実装) |
| | 小数 `+ - *` 小数→小数。小数 `/` は **TYP001**(丸め未決定) |
| | 金額<C> `±` 金額<C>→金額<C>。通貨違いは TYP001。金額×整数、整数×金額→金額。金額 `/` は **TYP001**(端数処理未決定) |
| | 文字列 `+` 文字列→文字列 |
| `== !=` | 同型同士(列挙と文字列リテラルの比較を含む) |
| `< <= > >=` | 整数, 小数, 金額(同通貨), 日時, 日付, 期間。**文字列は TYP001**(照合順序未決定) |
| `&& \|\| !` | 真偽 |

## 3. 文の規則
- 引数・繰り返し変数は再代入不可(TYP002)。最初の代入で局所変数を宣言し、再代入は同型のみ。変数のスコープはブロック。
- エンティティのフィールド更新は、(1) アダプタ `取得` で得た局所変数に限り、(2) `取引:` の中で、(3) `ID` 以外、のときのみ可(TYP002)。更新は `資源.update` の Capability を要求する。
- `取引:` の入れ子は TYP002。
- 戻り型のある動作は全経路で `を返す` が必要(TYP003)。終端判定: 最後の文が返却、`取引:` の本体が終端、または `もし`…`そうでなければ:` の全分岐が終端。
- 式だけの文は呼出に限る(SYN001)。`結果` を返す呼出の結果を捨てると警告。

## 4. アダプタの型規則(ADR-0104)
| 操作 | 引数 | 戻り値 | Capability |
|---|---|---|---|
| 取得 | `(ID: Dの ID型)` | `D` または `選択<D>` | D.read |
| 一覧 | なし(絞り込みは未対応) | `一覧<D>` | D.read |
| 登録 | D の必須フィールドをすべて含む(ID 不可。選択型は省略可) | `D` または ID 型 | D.create |
| 更新 | `ID` + D のフィールド | `D` | D.update |
| 削除 | `(ID: …)` | `真偽` | D.delete |

## 5. 効果と Capability(ADR-0105)
- 効果: `pure`(宣言上の空集合), data.read, data.write, network.send, filesystem.read/write, device.camera/location/notifications。
- Capability: `資源.動詞`。ソースの動詞は 読取/作成/更新/削除、VAG では read/create/update/delete。
- 動作の必要 Capability = 呼んだアダプタ ∪ フィールド更新 ∪ 呼んだ動作の必要 Capability(推移閉包)。
- `必要` に無い Capability → SEC002。`必要` 未宣言で資源に触れる → SEC002(デフォルト拒否)。宣言したが未使用 → 警告。
- `効果` を宣言した動作が宣言外の効果を起こす → SEC001(TC-006)。
- **更新は読取を含まない**(C-03)。

## 6. 組込み値
`本人`: 動作の中でだけ使える 識別子型の値(現在の認証済み主体の ID)。代入不可(ADR-0119)。

## 7. 型推論
局所変数の型は右辺から決める(局所推論のみ)。引数・戻り値・フィールドは明示必須(公開 API は型明示: 技術仕様書 §4)。
